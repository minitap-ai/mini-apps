# Croissant

A neighbourhood bakery app: browse the menu, add to cart, check out for delivery or pickup,
track an order, collect loyalty points, order together as a family, and ask for a custom
cake decorated with your own photo. It runs on Android and iOS (Expo + React Native) and
also compiles for the web with react-native-web.

The backend is an Appwrite project: email-code sign-in, a database, Realtime, Storage, and
one function named `api` that serves the bakery's JSON API. The app only renders what that
API returns.

## Requirements

- Node 22 and npm
- Android: Android SDK and JDK 17
- iOS: Xcode with an iOS simulator

## Setup

```bash
npm ci
```

No environment variables are needed: the public Appwrite endpoint, project id and function
id are compiled in (`src/lib/backend/config.ts`). For local work you can override them:

| Variable | Purpose |
|---|---|
| `EXPO_PUBLIC_APPWRITE_ENDPOINT` | Appwrite endpoint (default `https://fra.cloud.appwrite.io/v1`) |
| `EXPO_PUBLIC_APPWRITE_PROJECT_ID` | Appwrite project id |
| `EXPO_PUBLIC_APPWRITE_FUNCTION_ID` | Function serving the API (default `api`) |
| `EXPO_PUBLIC_API_URL` | Call a plain HTTP API at this URL instead of the Appwrite function (local API server) |

## Run

```bash
npx expo run:android      # build and run on an emulator or device
npx expo run:ios          # build and run on the iOS simulator
npx expo start --web      # web, for a quick look
```

Deep links use the `croissant://` scheme with the same paths as the screens, for example
`croissant://menu`, `croissant://daily` or `croissant://orders/<id>`. On the web the same
paths work as URLs (`/menu`).

## Check

```bash
npm run typecheck         # TypeScript, strict
npm test                  # unit tests (vitest)
npx expo export -p web    # static web build in dist/ (single-page app)
```

The web build is a single-page app: serve `dist/` with every path falling back to
`index.html`.

## Native projects

`android/` and `ios/` are generated by `npx expo prebuild` and are not committed. A local
debug build:

```bash
npx expo prebuild
cd android && ./gradlew :app:assembleDebug     # JDK 17
cd ios && pod install && xcodebuild -workspace Croissant.xcworkspace -scheme Croissant \
  -configuration Debug -sdk iphonesimulator build
```

Bundle id and Android package: `ai.minitap.croissant`.

## Layout

| Path | What |
|---|---|
| `src/app/` | Screens (expo-router); every file is a route |
| `src/lib/backend/` | The only module that talks to Appwrite: API client, auth, Realtime, Storage, locale |
| `src/state/` | Session, cart and data-loading hooks |
| `src/ui/` | Theme and shared components |

Every interactive element has a stable `testID` (`data-testid` on the web).
